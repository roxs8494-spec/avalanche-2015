New game

Live: tap events as they happen. From video: open a LiveBarn download and tag while it plays; you can pause, rewind and jump back to any event.

Open a game file

A game prepared from the LiveBarn video (periods, clock, goals and penalties already filled in). Open it, then the video, and tag the shots.

Saved on this device

    Games are saved on this phone/computer as you go. Tap Export after each game so the app can include it.

    Open the LiveBarn video

    Choose the downloaded .mp4 file(s) for this game. If LiveBarn split it into several files, select them all; they play as one video. Nothing is uploaded.
